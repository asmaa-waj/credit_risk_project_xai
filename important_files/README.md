# Explainable AI Platform for Credit Risk Assessment

BSc thesis project — Department of Information Technology, Faculty of Mathematical Sciences and Informatics.

Three credit scoring models (Decision Tree baseline, Random Forest, XGBoost) trained on the Home Credit dataset and compared on predictive performance, with SHAP and LIME explanations delivered through an interactive dashboard for non-technical stakeholders (loan officers, compliance officers, applicants).

## Implementation Pipeline

1. Dataset Selection — Home Credit dataset (9 files) from Kaggle
2. Exploratory Data Analysis — target/predictor identification, class balance, missing values, correlations
3. Data Cleaning & Feature Engineering — imputation, outlier treatment, encoding, class imbalance handling, derived features (e.g. debt-to-income ratio)
4. Model Development & Comparison — Decision Tree (baseline), Random Forest, XGBoost
5. Comparative Evaluation — side-by-side metrics table across all three models
6. Explainability Integration — SHAP + LIME applied to the best-performing model
7. Dashboard Development — interactive predictions with SHAP/LIME explanations

## Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/asmaa-waj/credit_risk_project_xai.git
   cd credit_risk_project_xai
   ```

2. **Create a virtual environment** (Python 3.12+)
   - In PyCharm: `Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter → Virtualenv`
   - Or via terminal:
     ```bash
     python -m venv .venv
     .venv\Scripts\Activate.ps1      # Windows
     source .venv/bin/activate       # Mac/Linux
     ```

3. **Install dependencies**
   ```bash
   pip install pandas numpy scikit-learn
   ```
   (`requirements.txt` will be added once the modeling/XAI dependencies — xgboost, shap, lime, streamlit — are finalized.)

4. **Download the dataset**
   - Get the [Home Credit Default Risk dataset](https://www.kaggle.com/c/home-credit-default-risk/data) from Kaggle (requires a free Kaggle account)
   - Unzip it so the CSVs sit directly in `data/raw/`, keeping the `HC_` prefix (e.g. `data/raw/HC_application_train.csv`, `data/raw/HC_bureau.csv`, etc. — **not** nested in a subfolder)
   - Note: there is no usable `application_test.csv` in this dataset (only `HC_sample_submission.csv`, a Kaggle placeholder with no features). `step1_consolidate_data.py` creates its own 80/20 stratified train/test split from `HC_application_train.csv` instead — this is seeded (`RANDOM_STATE = 42`) so everyone's split is identical.

5. **Verify it works**
   ```python
   import pandas as pd
   df = pd.read_csv("data/raw/HC_application_train.csv")
   print(df.shape)  # should print (307511, 122)
   ```

6. **Run the preprocessing pipeline, in order**
   ```bash
   python step1_consolidate_data.py
   python step2b_handle_missing_values.py
   python step3_treat_outliers.py
   python step4b_encode_categorical.py
   python step5_feature_engineering.py
   python step6_class_imbalance.py
   python step7_feature_scaling.py
   python step8_final_validation.py
   ```
   Each step reads the previous step's output from `data/interim/` and writes its own output there. `step2a_missingness_report.py` and `step4a_categorical_report.py` are optional/informational — they only print a report and don't change any data. Step 6 needs `pip install imbalanced-learn` first. Step 8 writes the final versioned dataset to `data/processed/` — see `HANDOFF_modeling.md` for what to do with it.
